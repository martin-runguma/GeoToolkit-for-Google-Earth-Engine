about=GeoToolkit for Google Earth Engine provides a guided QGIS workflow for selecting an area of interest, choosing geospatial datasets, configuring processing options, and managing exports.
    Available products include Landsat RGB and false-colour imagery, Sentinel-2 RGB, Landsat and Sentinel-2 spectral indices, WorldPop population counts, Open Buildings height data, and building footprint vectors.
    Features:
    - Select an area of interest from a polygon layer and use the selected features or layer extent
    - Browse dataset descriptions, coverage information, reference images, and attribution
    - Configure imagery dates, cloud masking, index sources, years, bands, and vector tile IDs
    - Save raster outputs locally or export them to Google Drive
    - Submit supported vector exports as Google Earth Engine table tasks to Google Drive
    - Monitor current exports, elapsed time, and download history in the plugin
    - Add completed local downloads to the current QGIS project
    Notes: an internet connection and an authenticated Google Earth Engine-enabled Cloud Project are required for Earth Engine exports. Install the required Python packages in the QGIS Python environment when prompted. Dataset coverage, export limits, availability, licensing and attribution depend on each data provider.
